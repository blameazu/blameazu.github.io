前言
#

這篇來講特殊選才的心得

因為我比較廢所以選的都是資工系 omob

特殊選才結果
#

最後特殊選才結果是

  • 台師大資工 : 徑取
  • 清大資工 : 備取 2(備上)
  • 交大資工 : 正取

清大資工最後備到 九還是十

交大資工最後備到二(?)

為什麼會選特殊選才
#

啟發
#

說起來其實蠻懷念的，當初高一一開始才開始學 C++

然後高一上看到有一個 “資訊社”，然後就加進去了

進去之後有一次是聯合迎新，我參加的理由也只是為了交朋友 & 剛上高中想要多社交

結果迎新的時候學長姐邀請了一位靠著特選上成大資工系的學長 - Colten

他口條很好，而且很有趣

那堂課他跟我們講了特選的管道，以及競程的相關比賽路程

但我基本上都沒甚麼聽得清楚，當初只依稀記得某些圖示而以

但印象最深刻的大概有兩點

  1. Colten 說他學測睡過頭忘記去考學測，我那時候覺得很好笑，然後也覺得 : 靠，怎麼感覺那麼舒爽，假如我也這樣做的話，到時候周圍的同學不就會羨慕到爆ww
  2. Colten 現場打 apcs 實作第五題，那題好像是 DP，然後我只記得他打字很快、很帥

然後就這樣簡單的知道特選這條路，並且對於學測產生了一點點排斥感(因為有更輕鬆的路要走，我總想著偷懶qwq)

我在競程上的表現
#

(以下是流水帳，不想看的可以不要看)

我可以說，我在打競程的時候其實很擺爛又很賽

高一上的時候根本沒接觸到真正的演算法，就僅僅上選修課會看講義學(雖然都在讀化學)

所以開學我花了兩天學完 C++ 基礎語法(大概到遞迴前)，然後就一直刷基礎語法的題目

那時候刷題都是把 SA(學校選修老師)給的講義裡面的題目全部刷完

大概到第二次段考前吧，我才把遞迴學完，而且根本就不熟

在期末考前我才學到 BFS、DFS，反正整個的重心都還在讀書上

高一寒假

去參加了資訊社的寒訓

接觸到了競程的演算法，而且是超基礎的東西

二分搜、雙指針、STL 那些東西對我來說都是全新的東西

然後我寒訓靠著刷水題的實力勉強拿到了練習賽的第一

拿了第一的我感覺自己在競程上還蠻有天分的

且那時候看到隔壁的台南女中的學姊他打字超標準(就雙手放在鍵盤上 touch typing)

那時候我還是用雙指打字，而且左手的預設位置還放在 wasd，我真的羨慕那些很會打字的人

所以寒假的時候，想說有空，然後我就把剩下的時間全都拿來練習打字

那時候大概 wpm 20 -> 40 左右吧，挺爛的

但至少有硬生生地把手調到對的姿勢

高一下

就渾渾噩噩的打競程，說真的我那時候也還沒認真打

因為那時候還在拚成績，讀段考，想說要把成績顧好才能打競程

而且那時候給自己一個不接觸競程的理由是 : “看電腦會近視”

然後過沒多久就近視了…

高一下拿的成績大概就 TOI海選破台 TOI初選 100 多名

選了資訊社社長(單純覺得這個職位很水而且寫在學習歷程上會很加分，對，我那時候有認真在做學習歷程)

高一排名賽前好像認真學習 BIT 跟線段樹

然後高一排名賽靠著完全不會 DP 拿到了第五名

然後暑假的時候辦國中營，教進階班的時候才發現我不會DP

然後就跑去學起來了

之後聽到甘宸豪(社員)教矩陣快速冪優化費撥那其數列

我就覺得甘宸豪怎麼那麼強，很羨慕

然後就跑去把矩陣快速冪學起來了

暑假八月多的時候跑去清大辦的營隊 IONC 玩了一下

發現自己真的有點強又有點弱

強的點是，假如我會的東西，那我大概會贏別人

但假如我不會的東西，我都會輸給別人

所以那時候我突然意識到 “演算法應該是要學進腦子裡”

所以我開始認真理解演算法，然後就沒有然後了

IONC 回來之後，學到了一些怪科技(phi、treap之類的)，然後就跑去聽暑訓了

暑訓我邀了 tw87 跟郭育愷 回來上課

tw87 上課我感覺都有聽懂，但之後發現我根本都沒記起來

大概只記起來演算法走起來大概是怎麼樣

然後上課的時候感覺是誤闖天家

知識理解斷層太大的東西會讓我很想睡覺

然後郭育愷上課的時候我覺得一開始的經驗分享對我來說幫助很大

我聽到了一個很強的人，不怎麼打競程，然後可以打全國賽三等

且差二等只有一題決勝題

然後離二階也才差一題

這樣的學長在我心目中就超強的，感覺一輩子也無法超越

然後他交的東西也是我有稍微概念可以聽懂，斷層太大腦袋會自動關機

八月底 好像去比了成大邀請賽，跟科班的陳秉宏組隊

然後我切水題，被他帶上去佳作

那時候聽說成大邀請賽拿佳作就可以去特選成大資工

感覺很爽，而且那時候我校內成績感覺繼續讀下去學測成大資工很穩

所以我開始有點放飛了

把心思都飄向競程

高二上

九月打能競初試

那時候發現有 asdfg wonderhoi brinton 這些很強的學弟

我那時候心態整個大崩潰

我那時候甚至一直質問自己對於競程到底有沒有天賦

想說為甚麼拚了一年還是打不過這些學了兩個月的人

最後為了安慰自己，所以把原因歸咎於他們是科學班

所以得出來普通班永遠也比不上科學班的結論

所以當下就算打進了校內複試，依舊對自己很沒有信心

然後也對身旁的人產生懷疑、猜測、厭惡的心情

大概是那段時間需要一個人好好靜靜的心

但那時候我就越想越不爽，所以就很不爽的學演算法

然後打一打就打進全國賽了

打進全國賽我感覺就差不多了

那時候看 tw87 他高二的時候只有進全國賽就可以成大特選正取

所以我就覺得我打進全國賽也可以成大特選正取阿(?)

所以我就自然而然的想著自己已經有一間大學讀了

然後全國賽沒認真準備，就被打得稀巴爛

但我以我已經有間大學讀的心態開始放飛

且因為打能競我為了證明自己不比那些科班的弱

我逃避式的避開讀書，請了一些些公假

導致每個科目的課堂斷斷續續的，根本學不到什麼東西

(而且那時候看大家都很羨慕我有公假，我心裡就有點家豪成就感)

所以我成績往下滑，然後我想認真準備的時候發現我已經沒有那種想讀書的心情了

之後就因為成績爛而跟家裡吵了蠻多架

但我最後的選擇都是跟他們假裝我有在認真讀書

然後我就轉頭跑去玩社團或者學新奇的演算法

高二寒假

跟大家跑去台大辦的 IOIC 營隊玩

到那邊才發現有好多科技是真的好難

然後 IONC 的進階是 IOIC 的基礎讓我覺得很酷

而且看到 IOIC 的講師跟工作人員不是二階就是國手

那時候好想去台大…

高二下

抱著感覺透過全國賽的成績來算，選訓應該穩的心態去考

輕視比賽，然後輸在最終決策，沒進

那時候開始反省自己的心態

高三暑假

那時候覺得我特選青交應該備取可以上

正取要靠點運氣

所以我就沒有參加暑輔

然後暑假聽到的震驚的消息有好多

像是 brinton 當上國手

像是成大沒有要辦競程組的特選了

但想著反正我成績已經爛成這樣了，所以我還是繼續走特選好了

高三上

高三上開始了家豪的一生

從高二上的嘗試拯救，到高三的決定不讀書後

我每天晚上都會留在社部鬼混

因為我都跟我爸媽說我會認真在學校讀書

然後到學測前也是陸陸續續停掉補習班

因為我也發現我根本是定點刷新的人機，根本去浪費錢的

公假這時候也是想請就認真請

大概是只要有理由就請掉

我是真的很不想讀書，就算叫我在社部睡覺睡一個下午，我也不想回教室睡覺

然後就一路打初選、複選、南區、全國

阿公架一開始有很多人陪我請，然後後來越來越多人被刷掉

到了南區賽後的公假都是我一個人在社部打扣

那時候精神狀態有點厲害

我很喜歡邊聽哈基米邊打扣

然後那時候也沒幹嘛，就學 flow，打 atcoder，打 TOJ

感覺在跟高二差不了多少的實力再戰 NCCU(全國賽)

然後我就估著估著，感覺我的實力沒進步，但比我強的大概都畢業了

所以我估著自己可以拿個三等，眼望一等

然後就拿了個中間值，二等獎

保送進選訓

當初覺得很高興，感覺二等超賽

而且全國賽只有我一個靠喇分喇那麼開心打好的

然後我就一路開開心心的打打打打進選訓

打進選訓後就覺得我大概差不多就這樣了

但有點想拚 2!

所以我就認真打了一下 1!，然後很驚險地用 第八名滑進2!

打進2!後，估了一下，假如自己認真練習又認真準備又認真打比賽

大概可以拿國手，但基於某些原因，我好不想當國手

所以我 2! 就隨便亂打了

最後打到第七，APIO逆上第六

總觀我在競程的一路上

可以發現我在競程的實力很弱

而且一大堆題目都不會寫，純靠實作能力扁人而已

所以我說這麼多，大概也只是想說

堅持到最後的人通常都可以笑最大聲 哈哈

成績
#

有可能有人會很有疑問

問特選會不會看在校

反正我是不知道，但我覺得我撇掉高三成績大概還算不錯

反正我高二下前的繁星%在前30%左右

然後高一繁星%好像 11%左右

也有可能是因為我那時候成績跟競程都要顧，所以才導致我高一二競賽很爛之類的

特選過程
#

前言
#

以下就是特選過程的過程了

大概會很短，因為我有點忘記了

報考
#

當初報了三間學校

  1. 台師大資工
  2. 清大資工
  3. 交大資工

會報這些是因為 tw87 也報這些

然後成大沒辦，所以我沒辦法報

然後台大只有資安組，我也沒辦法報

當初想報台師大而不是中字輩是因為，看歷屆成績發現中字輩會故意把很強的人刷掉

然後我覺得我有點比他們學校強，所以不浪費時間、車錢、報名費，所以不報

最後選台師大來當練面試

台師大
#

一開始在做書審的時候很躁

感覺這種會穩上的學校根本不用太認真做備審

所以我就到網路上隨便找人的心得，抓個幾句下來改

然後隨便改一改就丟上去了

然後要面試前幾天突然颱風要來

我面試衣服跟褲子都買好的情況下，我還是不想去面試

然後師大突然就給我一個逕行入取，直接透過書審成績正取，不用在面試

所以讓我感覺面試很簡單

清大
#

清大的書審有在認真做

然後丟上去發現不管做得多好看還是醜，他都依照這個人的競賽成績去評

所以面試的時候我也覺得差不多是看競賽成績

然後我就沒準備面試

現場面試得時候好緊張，一直抓領帶

對著自我介紹的簡報一直忘記我在寫什麼

然後後面講題目的時候戳到我不會的數三環

然後就拉了一坨大的 : 備取二

備取公布的那天是我全國賽的前一天

讓我超不爽的

交大
#

然後因為我知道清大備二還是會上，但我不爽就是不爽

然後就很不爽地去打全國賽，拚盡全力拿了二等獎

二等獎意味著交大特選也穩正取了(大家都這樣講)

所以我就也沒準備面試

去那邊面試就繳獎狀證明，被卡車嗆

然後就乖乖地領個正取了

總結
#

上面這麼短的三段就是我對於特選的心得

真正會寫長的話 大概都是旅遊中的趣事

但我對於特選的結論就感覺類似是 p2w 的感覺

你只要競賽成績打得足夠好，不管你長怎樣

不管你成績多差，不管你口條再不好

就算你穿著拖鞋配海灘褲，教授還是會把你撈進去

畢竟清交不是台大，他們還是弱了點，得搶學生。

選交不選清的理由
#

其實我高一的時候對於清大有著憧憬

因為我有去參加 IONC 所以我覺得清大感覺很好

但因為學長們都選交大資工

而且清大還給我備取二，我超級不爽的

所以就看扁清大，然後跑去交大

論進交大的門檻
#

我大概認為全國賽拿個三等就可以進了

畢竟三等獎還是很稀有，大概怎樣都可以輪得到你

然後進交大也不一定要打競程

有幾個開發的有進，然後我們學校有個台大資安的也有用一般組拿到不錯的成績

論進清大的門檻
#

APCS 5 5 or APCS 5 4 or APCS 4 4

區賽佳作以上

這種都能進

不是說清大不好，只是好的都被交大收走了ㄏㄏ

論進成大的門檻
#

會AI

他們捨棄掉競程組的名額

然後加開名額的乙組

你只要會用 AI，然後 prompt 下的正確就可以進

感覺台灣升學就是一個笑話

你是不是可以特選的人
#

說這麼多看起來特選很輕鬆，其實我也覺得

但我看身邊的人好多都特選失敗的

所以我給幾個不知道對不對的建議

  1. 你讀私校(僅限南部人ㄏㄏ)的話，特選就算了

    因為私校通常比較封閉，你接觸到一些活動以及知識層面的圈子太窄了

    有可能連普通競賽都沒參加多少場

    而又因為校名的關係，大概都會吃屎

  2. 你真的有認真評估嘛?

    你要比對歷屆版單，然後風險評估

    不要做井下的青蛙

  3. 你運氣好嗎?

    運氣不好不要參加，不然清大會給你備取，讓你很不爽

  4. 特選是窄門，你確定你在這門領域是頂尖的嗎?

  5. 你是怪人的話，應該可以去特特看台大。

勉勵的話
#

理論上沒有永遠贏不了的敵人。

因為你只要每天進步比他多一點，總有一天會超過他的。

當然，假如你夠強的話，就算擺爛，其他人也要花很多時間才能追上你。
